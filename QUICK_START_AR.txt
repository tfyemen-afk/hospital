  دليل التثبيت السريع - منصة المستشفى على XAMPP
═══════════════════════════════════════════════════════════════

📋 الخطوات السريعة:

1. ✅ شغّل XAMPP
   - افتح XAMPP Control Panel
   - شغّل Apache و MySQL

2. ✅ أنشئ قاعدة البيانات
   - افتح: http://localhost/phpmyadmin
   - أنشئ قاعدة بيانات جديدة باسم: hospital_db
   - Collation: utf8_general_ci

3. ✅ ابدأ التثبيت
   - افتح المتصفح: http://localhost/hospital/index.php/install/index
   - اتبع الخطوات في معالج التثبيت

4. ✅ معلومات قاعدة البيانات (للتثبيت)
   - Hostname: localhost
   - Database: hospital_db (أو الاسم الذي اخترته)
   - Username: root
   - Password: (اتركه فارغاً)

5. ✅ بعد التثبيت
   - سجّل الدخول من: http://localhost/hospital/

═══════════════════════════════════════════════════════════════
  ملاحظات مهمة:
═══════════════════════════════════════════════════════════════

⚠️ تأكد من:
- PHP 5.6 أو أحدث مثبت
- MySQL يعمل
- Apache يعمل
- جميع امتدادات PHP المطلوبة مفعلة

📖 للتفاصيل الكاملة، راجع ملف: INSTALL_AR.md
